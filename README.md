# Preschool OS

India-first preschool platform: admin panel, teacher app, parent app and public website. This repo holds the early demos and pitch material.

| Folder | What it is |
| --- | --- |
| `admin-demo/` | Clickable admin dashboard demo (single HTML file, mock data) |
| `website-sunshine-kids/` | Sample public school website (Sunshine Kids, placeholder content) |
| `website-little-wings/` | Little Wings Kindergarten website with animations and a visit-booking form |
| `pitch-deck/` | 8-slide pitch deck source (slide HTML plus `deck.json`) |

## Notes
- Each demo is one self-contained `index.html`; open it in a browser. The Little Wings page loads Tailwind from a CDN.
- Contact details, programs, timings and safety claims on the Little Wings page are unverified. Confirm them with the school before showing it publicly.
- The gallery photos are AI-generated and marked illustrative. Replace them with the school's own photos, with parental consent.
- The visit form shows a thank-you message only and does not store leads yet.
